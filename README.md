## 选哪个套餐？按用户类型说清楚

这个问题问的人不少，把逻辑理一下：

**你是电信宽带用户，需要访问国内或跑代理节点**：首选洛杉矶 Pro 系列。电信 CN2 GIA 双向优化，晚高峰延迟稳定在 155-180ms，丢包极低。MALIBU 年付套餐预算最低，够用就行；如果需要更大内存或流量，往上选 TINY 或 STARTER。

**联通/移动用户，对性价比敏感**：洛杉矶 EB 系列更合适。回程走 CMIN2，对联通和移动用户来说路由同样是优化线路，价格比 Pro 系列低一档。LAX.EB.WEE 年付 39.9 美元，比 Malibu 还便宜 10 美元。

**主要用途是国际业务或出海建站，不特别需要访问国内**：T1 系列。10Gbps 端口，AMD EPYC 9005 最新平台，流量超出后切限速模式，价格也更平。

**香港节点，追求极低延迟（国内用户）**：香港 Pro 系列实测国内延迟在 20-50ms，感知上最好，但价格高出不少，入门年付 $298.88。如果预算有限，香港 EB 系列也能走 CMI 三网优化，延迟也在可接受范围内。

有一点值得说：DMIT 的定价续费不涨价。第一年买的价格，后面每年续费还是这个数，没有"首年优惠陷阱"。长期持有成本可以预测，这点对年付套餐来说挺重要。

## 常见问题

**DMIT 49.9 美元的 Malibu 套餐经常有货吗？**

不常有。这是限量补货套餐，每次上架量有限，通常在几小时到一两天内售罄。有时候一个月补一次，有时候要等更久。如果现在能看到有货，基本上不用犹豫太久。

**Malibu 和 DMIT 常规 Pro 月付套餐有什么差别？**

配置上 Malibu 是入门规格（1核1G），常规月付的 TINY 是 1核2G，STARTER 是 1核2G 带更多流量。线路质量都是同样的三网 CN2 GIA 回程。Malibu 的优势是单价低——年付 $49.9 换算下来每月不到 $4.2，而常规最低月付 TINY 是 $9.9/月，差距明显。

**流量超出了会怎样？**

降速不停机。Malibu 月流量 1000GB 超出后切换到 2Mbps 继续跑。对个人轻度使用来说够用，重度传输业务不太适合。

**移动用户适合 Malibu 吗？**

适合，但不是最佳选择。Malibu 移动去程走 CMIN2，三网回程走 CN2 GIA，对移动用户来说线路也有优化，不是走普通国际线路。不过如果你主要是移动宽带，洛杉矶 EB 系列（CMIN2 回程）可能体感更顺，而且价格比 Pro 系列低一档，可以对比看看。

**DMIT 的 VPS 可以用来建站吗？**

完全可以。Pro 系列是原生 IP，实测大部分主流服务解锁正常。如果需要特定流媒体解锁，建议购买前先测一下对应节点的 IP。Netflix 在 Pro 系列上通常只能看原创内容，这点不如住宅 IP 套餐。
